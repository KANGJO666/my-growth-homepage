# 我的成长主页

这是一个用 HTML、CSS 和 JavaScript 制作的个人学习记录和技能展示网页。`index.html` 是完整网页，包含三个可切换的视图：关于我、学习记录、技能与项目；所有样式和脚本都包含在这一个 HTML 文件中。

## 使用方式

直接用浏览器打开 `index.html`。点击顶部导航切换视图，填写首页表单可以将记录保存在当前浏览器，并在学习记录视图查看；技能与项目视图中的实验记录工具可以生成一条待人工核验的示例记录。

本地记录保存在浏览器中，清除浏览器数据或更换设备后可能无法查看；它不会自动上传到仓库。

## 持续更新

通过编辑 `index.html` 补充学习记录和项目经历，核对内容后将改动提交到 GitHub。学习记录的具体日期和个人 GitHub 主页待本人补充。

## 网页说明

这个网页记录了我在软件工程、机器人学习和具身智能方向上的学习经历，包括个人介绍、三条学习记录、技能展示和项目实践。我写下了模型复现、双臂机器人仿真与真机适配中遇到的问题，也介绍了黑盒模型数据采集方案和《光迹探真》项目。网页提供实验记录工具和本地留言功能，方便我练习前端交互并记录新的想法。接下来，我会核对学习时间，补充可公开的项目代码、实验结果和复盘，并定期更新 GitHub 仓库，让它持续反映自己的学习过程。
